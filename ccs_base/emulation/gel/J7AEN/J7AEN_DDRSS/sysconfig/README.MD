New generation of J7AEN 3733MT/s, J7AEN-DDRConfig-LP4-50-1866.gel
 - using DDRConfig tool 
 - Need to adjust freq. dependent paramters, like. RL, WLS, WL and nWR 
 - Need to adjust device density paramters (in QT, fixed SDRAM Size in J7AEN, 8Gb/channel) 
 - from default values of all paramters, only RL, WLS, WL and nWR are changed for 3733 MT/s. 
 - All other paramers are used as default. 
 - one difference with AM62A silicon configuration:" CS ODT overide, silicon: disable, QT: enable (default)
    + no effect in QT sim
 - ODTon and ODToff: default '0' while JEDEC spec requires certain values with freq. 
    + used default values. '0' 
 - default value: values are shown up when the tool is open.
