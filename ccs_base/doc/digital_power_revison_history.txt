Digital Power Device Support Package
====================================

1.1.5
-----
Added support for additional device IDs:
 UCD3138: 0x547F
 UCD3138064: 0x047F 0x447F 0x647f
 UCD3138A64 and UCD3138128: 0x0447

-----
Added support for device id validation of hex based firmware (.x0, .hex, .srec)
Added support for latest UCD3138128 c revision 0x3447
Converted all .h, .cmd, .asm to Unix EOL characters


1.1.3
-----
Added new flash files for further support in CCSv7; Added basic Support for UCD3138A64


1.1.2
-----
Added new DLL files to fix output files/flashing in CCSv7; Added GEL support for UCD3138 family


1.1.1
-----
Added peripheral modules for UCD3138A, UCD31338064, UCD31338064A, UCD31338128, and UCD31338128A; Updated UCD3138
